# 203实验室 PIPER 机械臂双目视觉引导自主抓放与双臂协同控制系统

> 本工程为实验室松灵 PIPER 6-DOF 机械臂基于 ROS 2 Humble 与 Intel RealSense D435 深度相机打造的视觉伺服自主抓放与双臂协同控制系统。
> 系统具备端到端离线 Web 交互总控台、原生 Canvas 3D Gazebo 风格数字孪生轨迹视口、在线 6 点手眼标定、笛卡尔直线柔顺下探与安全防撞拦截机制。

1. **三栏式 Web 研发总控台 (`:8080`)**：
   - **A 臂专属栏**：独立硬件状态、基座坐标解算、微调参数、一键抓放与 6 点手眼标定。
   - **B 臂专属栏**：独立控制、轻摇认臂、拖动示教、微调参数与外参管理。
   - **双臂配合栏**：相机全局视野、点击选点评估、双臂协同接力规划、外参标定表与 CAN 热插拔诊断。
2. **导师汇报与演示专用单臂控制台 (`:8081`)**：
   - 界面极简高雅，去除复杂配置面板，仅保留一键抓取放回、点击选位搬运与安全复位。
3. **Gazebo 交互风格 3D 桌面与轨迹视口**：
   - **鼠标左键**：360° 无死角自由旋转（Orbit 绕观察中心旋转）。
   - **鼠标中键 / 滚轮拖拽**：相机视平面平移（Pan 移动观察中心）。
   - **鼠标右键拖拽 / 滚轮滚动**：平滑拉近拉远（Zoom）。
   - **快捷键**：`R` / `Home` 复位透视、`T` 垂直俯视、`F` 正视前视、`S` 侧方视角。
4. **悬浮参数微调卡片 (Tooltip 指南)**：
   - 鼠标悬停于 `下探`、`X偏`、`Y偏`、`力矩`、`开度` 上即刻弹出详细物理含义、安全门限与调参建议。
5. **断电重启与时序安全保护**：
   - **预开爪阻塞校验**：在开始下探前必须确认夹爪物理开度已达到 `>= 42mm`，若因断电未就绪则重发指令并自恢复，彻底杜绝夹爪闭合下压顶撞方块。
   - **限矩无损抓持**：采用 `grasp_target_mm: 26.5mm` 搭配 `350 mN·m` 柔顺力矩，避免压损 3D 打印方块与过流发热。
6. **手眼外参防撞包围盒**：
   - 在任何关节规划段实时检测末端连杆与架设的 RealSense 机身的安全距离，违规轨迹一律毫秒级安全拦截。

## 3. 手眼标定几何模型与数学原理

本系统采用 **眼在手外 (Eye-to-Hand)** 架构，主相机固定于机械臂工作台上方桁架俯视全局。

### 坐标变换关系
对任意机械臂 $i \in \{A, B\}$，其基座坐标系到相机光学坐标系的刚体变换为齐次矩阵 $T_{base\_i}^{cam} \in SE(3)$：
$$P_{base\_i} = T_{base\_i}^{cam} \cdot P_{cam} = \begin{bmatrix} R_{3\times3} & t_{3\times1} \\ 0_{1\times3} & 1 \end{bmatrix} \begin{bmatrix} X_{cam} \\ Y_{cam} \\ Z_{cam} \\ 1 \end{bmatrix}$$

### 标定关键结论（关于摄像头变动）：
> [!IMPORTANT]
> **若摄像头高度往上抬或移动，必须重新进行手眼标定！**
> 原因：$T_{base}^{cam}$ 直接锁定了相机镜头光心与机械臂基座的相对空间位姿。当相机高度发生位移 $\Delta Z$ 时，不仅平移向量 $t_z$ 发生改变，相机的深度尺度和投影视场角对应关系也将改变。若沿用旧矩阵，机械臂解算出的目标三维坐标必然严重失准（抓空或砸桌）。

### 在线 6 点标定流程：
1. 开启示教拖动（点击控制台【示教】），将方块放置在桌面点 1。
2. 移开机械臂，点击控制台【1. 锁方块】（视觉自动提取 Tag 3D 坐标）。
3. 拖动手臂将夹爪指尖精准轻触 Tag 中心点，点击【2. 记臂尖】。
4. 重复 4~6 个分散点（分布于不同象限与高度）。
5. 点击【保存外参】，系统通过 Kabsch / SVD 正交普鲁克分析解算最优 $R, t$，并将重投影 RMSE 控制在 3~5mm 以内，结果自动写入 `dual_arm_config.json`。

## 4. 关键控制概念澄清：“锁臂” vs “急停”

> [!WARNING]
> **网页中的“锁臂”按钮绝不是急停按钮！**
> - **“锁臂”按钮的真实作用**：调用 `exit_teaching_mode()`。它使机械臂退出零重力阻尼示教状态，恢复 CAN 伺服闭环位置锁定模式（`ModeCtrl(0x01)` + 读取当前各关节角并保持）。电机**处于持续通电、闭环抗外界扰动的正常工作状态**。
> - **真正的急停 (E-Stop)**：应在发生剧烈机械碰撞、关节超限或程序异常时使用。真正的急停应直接拍下硬件线缆上的**红色蘑菇头物理急停按钮**，或软件底层调用抱闸下电指令 `MotionCtrl_1(0x01)` 切断电机使能。

## 5. 项目工程文件清单

- `piper_dual_arm_server.py`: ROS 2 双臂驱动控制核心服务（200Hz 关节发布、FollowJointTrajectory Action 动作服务器、CAN掉线热管理与轻摇认臂）。
- `calibration_visualizer_server.py`: 8080 双臂科研总控台与 8081 单臂演示台双 Web 服务端，集成 AprilTag 3D 姿态对齐、逆解轨迹生成与安全防撞校验。
- `web_ui_components.py`: 前端组件库，内置 100% 离线 Canvas 3D Gazebo 交互视口、CSS 参数悬浮卡片、三栏响应式控制台。
- `kinematics.py` / `piper_kinematics_engine.py`: 松灵 PIPER 6-DOF 机械臂正向运动学（FK）与数值/解析逆运动学（IK）引擎。
- `stream_win_camera.py`: Windows 端外接辅助广角摄像头低延迟推流服务（端口 8082）。
- `start_dual_arm_system.sh`: Ubuntu 端全链路一键拉起脚本（相机、双臂驱动、8080/8081 双网页）。
- `dual_arm_config.json`: 双臂手眼标定矩阵、夹爪参数、安全防撞包围盒持久化配置文件。
